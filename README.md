# Address Book Management System

## Overview

The Address Book Management System is a C-based application developed to make managing contact information easier and more organized.

It provides a simple menu-driven interface through which users can add new contacts, search for existing ones, update details, delete records, and view their saved contacts. The application also uses file handling to retain contact information between program executions.

## Features

- Add new contacts with the required details.
- Search for contacts using available search options.
- Update contact information whenever needed.
- Delete contacts that are no longer required.
- Display the saved contact list.
- Store contact records in a file for future access.

## Technologies and Concepts

- **Language:** C
- **Data Handling:** Structures and Pointers
- **File Operations:** File handling for storing and retrieving contact records
- **Programming Approach:** Modular programming
- **Other Concepts:** String manipulation and input validation

## Project Organization

The application is organized into separate source and header files, keeping contact management and file operations independent from the main program.
